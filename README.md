# 한달 한국사 · Korean History in a Month

> A 31-day study site for the Korean History Proficiency Test, level 심화.
> Concepts with photos and a hover glossary, 1,083 original practice questions in the style of past exams, and a day-by-day plan. No build step, no dependencies.

2026년 10월 17일 한국사능력검정시험 심화 대비용 학습 사이트입니다.
1년 전 조금 공부해 본 상태에서 한 달 만에 심화 1급(80점), 최소 3급(60점)을 목표로 구성했습니다.

저장소 이름은 `korean-history-in-a-month`입니다.

## 여는 방법

`index.html`을 더블클릭하면 바로 열립니다. 설치나 인터넷 연결이 필요 없습니다.

로컬 서버로 열고 싶으면 이 폴더에서 아래를 실행하고 http://localhost:8777 로 접속하세요.

### 진도 몰아치기

학습 플랜 탭에서 **진도 마감일**을 고르면, 남은 진도(새 개념이 있는 날)를 오늘부터 그날까지 고르게 나눠 하루 몫을 정합니다. 대시보드의 오늘의 학습에 오늘 몫이 체크 목록으로 뜨고, 개념 정리의 "오늘 범위"는 오늘 몫 전체를 한 화면에 이어서 보여 줍니다. 오늘 몫을 다 끝내면 다음 몫을 당겨 올 수 있고, 진도를 모두 끝내면 실전 기출·맞춤 문제·약점 분석으로 안내합니다. 기본 마감일은 `js/data/plan.js`의 `SPRINT_END`입니다.

### 맞춤 학습

문제를 풀 때마다 사이트가 사용자에게 맞춰 바뀝니다. 기록은 모두 브라우저 안에만 있습니다.

- **주제 숙련도**: 56개 주제마다 0~100%. 풀 때마다 최근 결과 쪽으로 당겨서(연습 35%, 실전 기출 45%) 최근에 맞히면 금방 오르고 틀리면 바로 내려갑니다. 개념 정리 목차에 색 점(빨강·주황·초록)으로 보입니다.
- **복습 일정**: 틀린 문제는 1일 → 3일 → 6일 뒤에 다시 나오고, 세 번 연달아 맞히면 빠집니다.
- **확인 문제**: 학습 모드에서 틀리면 같은 주제 문제를 2문제 뒤에 한 번 더 끼워 넣습니다 (한 판에 5개, 한 주제에 2개까지).
- **문제 고르는 순서**: 복습 차례 → 안 푼 문제(약한 주제부터) → 틀렸던 문제 → 맞힌 문제(약한 주제부터).
- **맞춤 10문제**: 복습 차례 문제와 배운 범위의 약한 주제로 10문제를 고릅니다. 연습 문제, 대시보드, 약점 분석에서 시작합니다.
| 연표·암기 | 순서 나열 문제 대비 핵심 연표 약 200개 |

## 쓰는 순서

1. 대시보드에서 오늘 날짜의 학습 범위를 확인합니다.
2. "개념 보기"로 해당 주제를 읽습니다. 각 주제 맨 아래 시험 포인트를 꼭 보세요.
3. "오늘 범위 문제 풀기"로 10문항을 풉니다. 학습 모드는 답을 고르면 바로 해설이 나옵니다.
4. 플랜에서 그날을 체크하면 진도율에 반영됩니다.
5. 시험 전 5일은 새 개념 대신 오답 노트와 실전 모드만 반복합니다.

## 문제 출처

문제는 모두 실제 출제 방식에 맞춰 새로 만든 연습 문제입니다. 공식 기출문제는 국사편찬위원회 자료로 공공누리 제4유형(출처표시, 상업적 이용금지, 변경금지)이라 원문을 옮기지 않았습니다. 기출문제는 [한국사능력검정시험 홈페이지](https://www.historyexam.go.kr/)의 시험자료실에서 받을 수 있습니다.

실전 기출 탭에는 회차별 정답·배점(공식 정답표 기준)과 이 사이트가 붙인 시대·주제 태그만 들어 있습니다. 문제지 PDF는 사용자가 직접 받아 고르면 그 브라우저(IndexedDB) 안에서만 열리고 서버로 올라가지 않습니다. 로컬 `기출/` 폴더는 `.gitignore`와 `.vercelignore`로 배포에서 빠집니다.

## 배점 참고

심화는 50문항 80분, 문항당 2점입니다. 1급 80점, 2급 70점, 3급 60점.
근현대(개항기·일제 강점기·현대)가 전체의 약 40%라 이 구간 정답률이 등급을 가릅니다.
플랜 2단계(16~29일차)가 여기에 집중되어 있습니다.
